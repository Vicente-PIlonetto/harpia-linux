# Fly

**Fly** será o orquestrador de perfis e dotfiles da Harpia Linux.

Nesta fase do projeto, apenas a arquitetura foi definida. A implementação executável será iniciada depois que a base pós-boot estiver estável.

Veja:

- `build/roadmap/post-boot-fly.md`
- `README.md`


## Perfis previstos

```text
harpialand  -> Hyprland + dotfiles oficiais da Harpia
caelestia   -> Hyprland + Caelestia Shell/dots
plasma      -> KDE Plasma
```

O Harpialand será o perfil Hyprland oficial da distribuição.
