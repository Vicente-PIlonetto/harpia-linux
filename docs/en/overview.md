# Overview

Harpia Linux is an experimental Linux From Scratch-based distribution. The approved initial architecture targets x86_64 and uses systemd, UKI and systemd-boot. Debian is the build host, not the distribution package base.

The project prioritizes explicit user choices, local/exportable logs, no telemetry, and tested recovery. No installer, release image, package manager implementation or supported release exists yet.

See [current status](current-status.md). The project name and identity remain subject to availability checks, and the original code has no selected license.
